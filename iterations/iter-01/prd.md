# PRD · iter-01：平台约束兜底 + 主题校准

> **等级**：prd（已定未做，拍板级）｜ **定稿**：2026-09-18 评审清零 + 用户确认
> **关联**：`draft/讨论记录.md`（过程）· `todo.md`（执行清单）· `dev-notes.md`（实现思路）

## 1 · 改什么、为什么

- **背景/动机**：工具复制到公众号的产物存在平台兼容缺口（外链/锚点/暗色主题/图片可靠性），且平台"死规则"全靠人肉记忆，会漂移；主题未经方法论校准，视觉"花"。
- **目标**：让复制进公众号的 HTML **不掉格式、可自动校验**；主题排版按"灰阶承重"方法论整体升级；拆分版与单文件版主题对齐到 18 套。

## 2 · 验收标准

- [ ] 新增源头关校验脚本，拆分版 + 单文件版主题数据全过（ERROR 清零才通过）
- [ ] 复制暗色主题文章 → 自动换浅色主题 + 弹提示说明（预览仍保留暗色）
- [ ] 复制含外链的文章 → 外链全部变为文末脚注，产物中除公众号链接外无外链 href
- [ ] 复制含页内锚点的文章 → 锚点 href 被移除（文字保留）
- [ ] 产物存在硬违规（外链未转/锚点残留/var 残留）→ 复制被拦截，提示具体原因
- [ ] 复制含外链图片的文章 → 弹提示列出外链图片清单（base64 图片不受影响）
- [ ] 拆分版主题下拉 = 18 款，与单文件版一致
- [ ] 18 套主题通过"文本色灰阶"源头规则（饱和文本色清零）
- [ ] `bash scripts/verify.sh` 全绿；用户浏览器实测复制效果满意

## 3 · 影响面

- **涉及模块/文件**：`js/app.js`（拆分版复制流程）、`js/themes.js`（拆分版主题，补 9 款+校准）、`single-file.html`（单文件版内嵌 JS+主题，校准）、`index.html`（下拉补 9 项）、`scripts/verify.sh`（集成源头关）、新增 `scripts/check-themes.mjs`、`project-docs/system/*`（现状同步）
- **实体/结构变化**：☐ 无 ｜ ☑ 有 -> 已过架构确认门（变化明细：主题数据结构不变，仅内容与复制逻辑；拆分版主题数 9→18，与单文件版对齐）
- **兼容性/迁移**：旧复制产物无需迁移；主题 key 不变（chenlu/dushi/…/youyu），老用户选择不失效
